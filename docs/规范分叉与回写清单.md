## 二、三代规范对照

| | 第一代 = 本仓库现行（含本地 clone 的 config/docs） | 第三代 = `E:\SkyrimAE` 实盘（09 月起） |
|---|---|---|
| **名称格式** | `{anchor}·{local} — {english} — {tags}` | `[母体作者] 中文 - 变体 (by 补丁作者) — {english} — 【标签】 【标签】` |
| **主体分隔符** | 密集点号 `·` | **禁用 `·`**，改用带空格的短横线 ` - ` |
| **作者位置** | 名称末尾标签池 `【作者·OFuzi】` | **名称最前** `[OFuzi] …`（母体作者置顶）；二次作者后置 `(by Leo)` |
| **标签间距** | `】【` 紧挨 | `】 【` 留空（"留白透气"） |
| **系列锚点** | 名称首位（与作者位冲突） | 让位给作者，系列下沉到标签池 `【系列·OBodyNG】` |
| **排序** | **明确不做**（`workflow.md`：不安装/删除/启用/禁用/排序） | **微排序覆盖铁律 + 样式一空 Mod 垫片**（核心增量） |
| **垫片机制** | 无 | 普通空 Mod 文件夹当视觉垫片（含基础 `meta.ini`），**不用** `_separator` 系统分隔符 |
| **工具链** | 9 个 `.ps1` | `E:\SkyrimAE\tools\*.py` 一批 |
| **规范载体** | `config/naming-rules.json` | 交接文档 + 脚本内嵌常量 |

关键事实：本仓库全域检索 `母体` / `留白` / `垫片` / `微排序` / `作者置顶` / `层级`
**命中数为 0** —— 第三代规范在本仓库内完全不存在。
